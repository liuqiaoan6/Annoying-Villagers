# Annoying Villagers Modpack
Minecraft 1.20.1 Forge modpack

## Version Info
Game Version: 1.20.1
Loader: Forge
Main Mod: Annoying Villagers
Includes: Custom Chinese translation resourcepack, battle addons, performance‑optimization mods

## Contents
1. Annoying Villagers main mod
2. Official addons (NPC Weapon Expansion, EpicFight Resurrection, Dual‑weapon addon)
3. Epic Fight combat animation mod
4. Performance optimization mods
5. Custom external Chinese translation resourcepack (with pack.png cover)
> Translation is an external resourcepack. No changes to mod jar files, translation survives mod updates.

## Installation
1. Install Forge‑1.20.1
2. Place all `.jar` mods into the `mods` folder
3. Put the translation zip into `resourcepacks`
4. In‑game: Settings → Resource Packs, enable this pack and move it to the top
5. Set game language to Chinese(Simplified)
