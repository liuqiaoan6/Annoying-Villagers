# 煩人的村民｜Annoying Villagers Modpack
Minecraft 1.20.1 Forge 主題整合包

## 📦版本資訊
遊戲版本：1.20.1
載入器：Forge
核心模組：Annoying Villagers（煩人的村民本體）
收錄項目：自製外置中文化資源包、戰鬥擴充附屬模組、效能最佳化模組

## 📁整合包內容
1. 煩人的村民主模組
2. 官方附屬模組（NPC武器擴充、EpicFight處決復活、雙武器相容套件）
3. Epic Fight 戰鬥動畫模組
4. 效能優化模組，降低遊戲延遲
5. **自製外置中文化資源包（內含 pack.png 封面）**
> 中文化採用外部資源包形式，無須修改模組jar檔案，更新模組不會遺失翻譯內容。

## ⚙️安裝步驟
1. 安裝對應版本 Forge‑1.20.1
2. 將全部 `.jar`
