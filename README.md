📦 版本信息
游戏版本：1.20.1
加载器：Forge
核心模组：Annoying Villagers（烦人的村民本体）
附带：自制中文汉化资源包、配套战斗拓展附属、基础性能优化模组

📁 包内内容
烦人的村民本体模组
官方拓展附属（NPC武器扩展、EpicFight处决兼容、双持兼容组件）
Epic Fight 战斗动作模组
基础优化模组，降低卡顿
自制外置汉化资源包（自带pack.png封面）
汉化为外置资源包形式，无需修改模组jar本体，更新模组不会丢失汉化

⚠️ 安装说明
安装对应版本 Forge 1.20.1
将全部 .jar 模组放入 mods 文件夹
汉化资源包完整放入 resourcepacks 文件夹
进入游戏 → 设置 → 资源包，启用汉化包，移至加载列表最上方保证汉化生效
游戏语言选择简体中文

❗ 注意事项
部分新增内容作者未提供词条，会保留英文显示，后续会持续更新汉化词条
手机端Pojav启动器可正常加载本整合包，内存建议分配4‑6GB
模组冲突：不要同时安装其他大量战斗类、生物重做类大型mod
